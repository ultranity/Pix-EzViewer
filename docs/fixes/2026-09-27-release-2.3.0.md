# 2.3.0 本地改动整理

本次从 2.2.6 整合网络、小说阅读和浏览器入口改动，版本号为 230 / 2.3.0。

## 用户可见变化

- API / OAuth 默认使用 Conscrypt ECH，保留 OkHttp 的超时、取消和鉴权。ECH 模式始终验证目标证书；设置页禁用不适用的旧 DNS / 证书选项。
- 仅将旧内置直连配置迁移一次；用户自定义 IP、替换主机及系统代理配置保留。历史开发版本的迁移标记保持兼容，避免重复覆盖用户选择。
- 图片 DNS 增加按主机缓存、后台刷新、失败退避及限时的最近有效地址，移除以 ICMP 可达性淘汰地址的逻辑。
- 修复小说 HTML 内嵌 JSON 和 Android ICU 正则兼容性，正文提供独立加载、失败与重试状态。正文解析失败不会以标题或简介成功掩盖。
- 侧栏增加 Pixiv 浏览器入口。

## 回归方法

- JVM 单元测试覆盖 DNS / ECH 缓存、迁移、重试范围、TLS socket 行为、小说解析及既有收藏和版本比较逻辑。
- `python3 scripts/check_novel_regex.py` 使用本机 ICU 编译生产小说正则。
- `Android Runtime Tests` 在 API 35 x86_64 模拟器执行指定的两类离线 instrumentation 测试：实际 ECH ClientHello 与 Android ICU 小说解析。发布 job 必须等待这些测试成功。
- 发布流程运行 JVM 回归、标准 release 构建，并校验 APK 签名与历史正式版本一致。

## 验证边界

离线 ClientHello 测试证明发出了 ECH 扩展和预期 outer SNI，不等价于当前网络下 Pixiv 服务端完成握手。网络连通性受运营商和远端服务影响。

`PixivConnectivityInstrumentedTest` 仅在显式开启 `liveNetwork`、设备已有登录态时使用；不纳入公共 CI。此次发布不将模拟器解析测试描述为真机阅读、浏览器导航或账号端到端验收。

2.2.6 的收藏状态保护仍按账号会话保存本地成功操作；跨设备同步和账号切换期间的完整请求隔离不在此次网络/阅读修复范围。
